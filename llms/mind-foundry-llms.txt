# Mind Foundry

> Mind Foundry is an Oxford University spin-out (founded 2016, Ewert House, Oxford, UK) that
> builds applied machine learning for high-stakes problems in defence, national security,
> insurance, infrastructure and government. It delivers deployed and integrated systems, not a
> public developer API.

IMPORTANT FOR AGENTS: Mind Foundry publishes **no public API**. There is no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL specification, no MCP server, no A2A agent card
and no /.well-known documents. Do not attempt to construct calls against mindfoundry.ai — there
is no endpoint to call. Commercial and technical engagement runs through the contact form.

This file was GENERATED by API Evangelist from publicly reachable material, because Mind Foundry
does not serve an llms.txt of its own (https://www.mindfoundry.ai/llms.txt returned 404 on
2026-08-25). It is a third-party profile, not a first-party document.

## Products

- [SENTRY: Sensor Fusion](https://www.mindfoundry.ai/sentry-sensor-fusion): Multi-modal sensor
  fusion — detects, classifies and tracks objects in time and space from raw, noisy sensor data.
  No public API.
- [NIGHTINGALE: Anti-Submarine Warfare](https://www.mindfoundry.ai/nightingale): AI-enabled
  acoustic intelligence for ASW; integrated with Thales systems to speed tonal analysis and
  triage of contacts of interest. No public API.
- [Nightingale and Thales case study](https://www.mindfoundry.ai/nightingale-and-thales-case-study)

## Retired developer surface

- OPTaaS (Optimization as a Service) — a Bayesian optimisation web service, Mind Foundry's only
  public API. Retired: optaas.mindfoundry.ai and demo.optimize.mindfoundry.ai no longer resolve,
  https://mindfoundry.ai/optaas returns 404, and the GitHub client repositories return 404. No
  retirement notice was published.
- [mindfoundry-optaas-client on PyPI](https://pypi.org/project/mindfoundry-optaas-client/) —
  the first-party Python client, still installable. Latest release 1.4.4, 2024-01-26. It cannot
  reach a live server.
- Mind Foundry Core / Platform — the self-serve ML platform that exposed tools and APIs.
  https://www.mindfoundry.ai/platform/core now redirects to the homepage.
